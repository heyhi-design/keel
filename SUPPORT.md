# Support

## Getting help

- **Setup questions** (cloning, filling in the profile, running your first session): start with
  `docs/setup-guide.md`. Most first-session problems are answered there.
- **"Is this the right tool for me" questions**: read the README's "What this is" and "What this
  isn't" sections first, then `docs/three-layer-model.md`.
- **Bugs and template issues**: open a GitHub issue using the bug report template.
- **Ideas for a better template, a missing eval case, or an unclear doc**: open a GitHub issue
  using the template-improvement template, or start a discussion if one is enabled.

## What this project can't support

This repository is a scaffold, not a consulting engagement. Maintainers can help with the
templates themselves: whether something is broken, unclear, or missing. They can't take on
calibrating your specific voice, auditing your specific practice, or building the pieces that
are particular to how you work. That's the paid fitting layer, not the free scaffold.

## Working with HeyHi

If what you need is that fitting layer (or you're not sure whether it's a template question or a
"help me apply this to my practice" question), that's a separate conversation. Let's talk about
what fits: [heyhi.design](https://heyhi.design).
