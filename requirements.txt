# Runtime dependencies for the Keel scaffold.
#
# The scripts here need a YAML parser and nothing else: the discovery search
# (skills/registry/skill-registry.py), the eval-case linter (skills/evals/lint_cases.py), and
# the operating tools that read YAML (os/resolve_operator.py, os/handoff_rotate.py,
# os/cold_start_check.py, os/start_load_check.py, keelson/close_check.py). The other tools
# (the id allocator, the worktree report, the status lint, the index generator, the
# separability and context-wall lints) use the standard library only. Everything else in this
# repository is templates and prose.
#
#   python3 -m pip install -r requirements.txt
#
# For the test suite, install the dev extras too:
#
#   python3 -m pip install -r requirements.txt -r requirements-dev.txt
#
# The optional memory adapter (memory/) has its own, opt-in dependencies —
# see memory/requirements.txt. Nothing here needs them; install them only if
# you use that adapter.

pyyaml>=6.0,<7.0
