## Full document skeleton, with placeholders

```markdown
# Proposal: [Client Name]

## Situation
[2-4 sentences: where they are, in language specific to their actual context]

## Stakes
[1-3 sentences: what happens if this stays unaddressed]

## The Work
[Specific, scoped description of what you'll do. Bullet the concrete deliverables if that
helps clarity; prose if the work doesn't decompose cleanly into a list.]

## Logistics
- Timeline: [your estimate]
- What we need from you: [inputs, access, decisions]
- Next steps: [what happens after this is signed]

[Pricing-deferral line — see below, never a number]
```
